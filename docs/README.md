# Manual do Sistema de Agendamentos CAp UFRJ

**Versão de referência: 2.6.9 · Atualização: 11/11/2026**

Este manual descreve a versão adaptada para o CAp UFRJ. Use o guia correspondente ao seu perfil. Os caminhos apresentados são relativos ao endereço do sistema; em instalações locais, podem incluir `index.php/`.

O conteúdo foi elaborado a partir do código desta versão e da documentação do classroombookings. As telas e instruções ainda devem ser conferidas no ambiente em uso, com contas de professor e administrador. Os espaços para capturas estão identificados em cada capítulo.
